"# gtasim" 

## Setup

For account-based daily streaks, apply the updated [Supabase schema](./supabase-schema.sql) in the project's Supabase SQL Editor. The streak repair and migration logic runs on the server after the schema is updated.

## Controls

- Driving: **W** accelerates; **S** brakes while moving forward and reverses once nearly stopped.
- Helicopter: **W/S** move forward/back, **A/D** yaw, **Space** climbs, and **Shift** descends. The flight gauge displays ground clearance, heading, vertical speed, and rotor speed."
